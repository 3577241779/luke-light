====================================================================
                  ✨ 卢克之光 V5.6 · 核心功能介绍与使用教程
====================================================================

本插件是一款基于【酒馆助手】的 渠道验伪防调包、七档无损破甲、流式抗截断与工具交付、晚高峰并发抢跑（PVP）、叙事防读心防 OOC、3D CG 雕像迪迦桌宠（神光棒化光变身）与云端自动更新 一体化脚本，支持面板可视化调节与特摄级全屏光流觉醒。
当前 V5.6 最新版即插即用，默认开关已调优，导入即享满血配置！

--------------------------------------------------------------------
🚀 安装、云端自动更新与三处控制台入口
--------------------------------------------------------------------
1. 首次安装：在【酒馆助手】中导入对应平台（ST酒馆适配 / TT酒馆适配 / 桌面版）的 JSON 脚本并启用，即可即插即用。
2. 云端自动更新（光之星轨 · 默认开启）：
   - 打开酒馆后会自动在后台静默检查 GitHub 与多路 CDN 镜像的最新版，自动拉取对应平台包并原地写回酒馆助手，下次刷新页面即刻升级，无需每次手动重下！
   - 你的全部个人形态开关、锁定波段与历史卷宗均独立存储，升级 100% 无损保留。
   - 如想改成手动，可去第 4 栏「防卫设置」顶部关闭「星轨共鸣 · 后台自动更新」，或随时点击「星轨巡检 · 手动检查更新」立即追新；刷新前也支持一键「时空回溯 · 撤回旧版」。
3. 控制台入口（全屏永远最多只留 1 个悬浮物，绝不挡视线）：
   - 扩展菜单入口：打开聊天框左下角魔法棒菜单，第一项即是四芒星徽标的「光之守护」（右侧实时显示 蓝灯守护中 / 石像待机）。
   - 侧边彩色计时器圆章：默认吸附在屏幕侧边，随当前破甲形态呈现五态呼吸光效（蓝灯 / 赤红 / 耀金 / 诺亚铂银 / 深渊黑曜血红）；疑似遭遇渠道偷换模型时变为红灯慢闪。
   - 3D CG 雕像迪迦桌宠 & 神光棒召唤（V5.6 全面重制）：
     * 在「防卫设置」点击召唤时，屏幕中央升起可点击 3D 金属神光棒——亲手点一下「啪！」双翼弹开 45°、垂直光柱中白光剪影破光凝实为 3D 迪迦，随后化作高能圣光彗星流光飞掠至屏幕边缘光柱现身！
     * 形态实时联动：切换不同破甲形态触发 Type-Change 能量环扫描变身（闪耀型切换 3D 鎏金雕像、诺亚自动展开动态铂银圣翼、凝视深渊伴随血红雷电裂隙降临 3D 黑曜血红黑暗迪迦）；雷达抓到渠道疑似调包时胸口计时器精准红灯急闪！
     * 内置 4 套 0KB 纯代码合成 1996 迪迦风格变身与单音红灯音效（默认静音防社死，可按需开启试听）。
     * 双击 3D 迪迦直接打开主面板；把迪迦拖向屏幕左右边缘松手自动合入带金色星点的计时器圆章，双击圆章即可轻量展开。

🛡️ 一、「光之雷达」页（验渠道 · 防缓存 · 控思考）
--------------------------------------------------------------------
1. 彩色计时器 · 信道守护（默认：开启）
   - 脚本总开关。每聊一轮自动比对请求模型名、回包实测模型版本、首字耗时与思考特征，在面板顶部实时统计「信号纯净 / 疑似调包 / 待定信号」。

2. 光波折射 · 防缓存（默认：关闭，描述：微调空格标点防中转站拿旧缓存糊弄）
   - 三档可选：关闭 / 微光级 / 棱镜级。在不破坏代码块、酒馆宏与台词引号的前提下做无感微调，专治中转站命中坏缓存导致的复读与敷衍。

3. 四大防调包护栏（默认：全开）
   - 主频锁定 · 禁降级调包（默认：开启）：自动删掉请求体里的备胎模型列表（models[]）并禁止静默降级；遇到 Gemini 官方原生格式时自动跳过防报错。
   - 光波采样 · 实时测速（默认：开启）：实时记录首字延迟、流式吐字速度与结束原因（finish_reason），同时作为空回/断章自动追击的前置观测器。
   - 波长记忆 · 基线比对（默认：开启）：自动学习当前渠道前 8 轮正常对话的速度特征，后续速度骤变时自动提示疑似偷换底层模型。
   - 信标核验 · 结构指纹（默认：开启）：核验返回 JSON 结构与思考块指纹，揪出“表面回显真模型名、底层偷换廉价模型”的伪装渠道。

4. 精神同调 · 思考强度（默认：跟随预设）
   - 四档可选：跟随预设（完全保留预设原有思考预算，零覆写，最稳妥）/ 低维 / 均衡 / 深度同调。

5. 主动探针与诊断维护
   - 展开圣域诊断报告 / 光波采样悬浮窗 / 真伪探针 · 渠道鉴伪 / 频段摸底 · 别名扫描 / 光波横幅昭示 / 导出圣域卷宗 / 复制排障信标 / 重铸护盾 · 全量自检 / 重置波长记忆 / 焚毁全部卷宗。

⚔️ 二、「形态破甲」页（七档破甲 · 抗截断 · 晚高峰抢跑）
--------------------------------------------------------------------
1. 作战波段 · 话术适配（默认：自动匹配）
   - 七档可选：自动匹配 / 3.8F·极速 / 4A·创作 / 4C·均衡 / 4H·高墙 / 4N·纯净 / 通用·全模型，支持点击「保存并锁定方案」永久固定波段（重开酒馆不丢失），更换模型后可点「恢复自动匹配」。

2. 迪迦五形态 + 终极圣域双神（默认：石像待机，按需一键切换）
   * 所有破甲仅作用于当轮发出的请求信号，你聊天框里的历史正文分毫不改！
   - 石像待机 / 空中型 / 复合型（日常推荐）/ 强力型（赤红刚力）/ 闪耀型（黄金圣辉）
   - ◤ 诺亚 · 太古圣翼 ◢：在全套破甲之上启动五百条对抗话术中性化清洗，既能过严审又不丢 system 人设与文风（开着桌宠时自动展开动态铂银圣翼）。
   - ◤ 凝视深渊 · 终焉暗域 ◢：终极黑化档，在诺亚全套能力之上执行彻底降权下沉，专啃最严苛的上游审查高墙（开着桌宠时降临 3D 黑曜血红黑暗迪迦）。

3. 能量续航 · 防半截断写（默认：自动接力）
   - 三档总控：关闭 / 续航叮嘱 / 自动接力；配套「收尾封印」「净界律令」「追击请示」「记忆凝缩（默认关）」「武装货舱 · 独立圣柜信道交付」。

4. 飞燕编队 · 高峰并发抢跑 & 时空回溯（PVP）
   - 飞燕编队（编队待命 / 飞燕一号·省流 / 双机齐射·2路 / 胜利合体·3路）、逆风突围 503 自动重连、时空回溯异常重演、断流看门狗、回溯时序罗盘与底部三枚手动战技键（破甲追击 / 断章接力 / 原波重演）。

⚠️ 游玩须知与叠甲
--------------------------------------------------------------------
- 关于破限：对于极高强度的题材，请直接采用「诺亚 · 太古圣翼」或「凝视深渊 · 终焉暗域」。如果依然出现道歉或拒答情况，请直接【删除这层楼，重新再发】，千万不要在本楼直接点重试/重Roll！
- 渠道兼容性：本脚本所兼容的渠道为【类脑公益站的各渠道，以及官方的第三方中转】。其他渠道的 Gemini 完全不兼容，可能存在报错和拦截。
- Bug 反馈：代码仍在持续迭代中，遇到问题可在面板第 1 栏点击「复制排障信标」或附上「圣域诊断报告」截图及时反馈！
