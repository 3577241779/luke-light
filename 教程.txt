====================================================================
                  ✨ 卢克之光 V5.5 · 核心功能介绍与使用教程
====================================================================

本插件是一款基于【酒馆助手】的 渠道验伪防调包、七档无损破甲、流式抗截断与工具交付、晚高峰并发抢跑（PVP）、叙事防读心防 OOC 与云端自动更新 一体化脚本，支持面板可视化调节与特摄级全屏光流觉醒。
当前 V5.5 最新版即插即用，默认开关已调优，导入即享满血配置！

--------------------------------------------------------------------
🚀 安装、云端自动更新与三处控制台入口
--------------------------------------------------------------------
1. 首次安装：在【酒馆助手】中导入对应平台（ST酒馆适配 / TT酒馆适配 / 桌面版）的 JSON 脚本并启用，即可即插即用。
2. 云端自动更新（光之星轨 · 默认开启）：
   - 打开酒馆后会自动在后台静默检查 GitHub 与多路 CDN 镜像的最新版，自动拉取对应平台包并原地写回酒馆助手，下次刷新页面即刻升级，无需每次手动重下！
   - 你的全部个人形态开关、锁定波段与历史卷宗均独立存储，升级 100% 无损保留。
   - 如想改成手动，可去第 4 栏「防卫设置」顶部关闭「星轨共鸣 · 后台自动更新」，或随时点击「星轨巡检 · 手动检查更新」立即追新；刷新前也支持一键「时空回溯 · 撤回旧版」。
3. 控制台入口（全屏永远最多只留 1 个悬浮物，绝不挡视线）：
   - 扩展菜单入口：打开聊天框左下角魔法棒菜单，第一项即是四芒星徽标的「光之守护」（右侧实时显示 蓝灯守护中 / 石像待机）。
   - 侧边彩色计时器圆章：默认吸附在屏幕侧边，随当前破甲形态呈现五态呼吸光效（蓝灯 / 赤红 / 耀金 / 诺亚铂银 / 深渊黑曜血红）；疑似遭遇渠道偷换模型时变为红灯慢闪。
   - 闪耀迪迦 · 光之伙伴（互动桌宠）：召唤迪迦立绘后圆章自动退隐（双击立绘开主面板）；把迪迦往屏幕左右边缘一拖松手，立绘直接化为带金色星点的计时器圆章，长按或双击圆章即可重新召唤迪迦。

🛡️ 一、「光之雷达」页（验渠道 · 防缓存 · 控思考）
--------------------------------------------------------------------
1. 彩色计时器 · 信道守护（默认：开启）
   - 脚本总开关。每聊一轮自动比对请求模型名、回包实测模型版本、首字耗时与思考特征，在面板顶部实时统计「信号纯净 / 疑似调包 / 待定信号」。

2. 光波折射 · 防缓存（默认：关闭，描述：微调空格标点防中转站拿旧缓存糊弄）
   - 三档可选：关闭 / 微光级 / 棱镜级。在不破坏代码块、酒馆宏与台词引号的前提下做无感微调，专治中转站命中坏缓存导致的复读与敷衍。

3. 四大防调包护栏（默认：全开）
   - 主频锁定 · 禁降级调包（默认：开启）：自动删掉请求体里的备胎模型列表（models[]）并禁止静默降级；遇到 Gemini 官方原生格式时自动跳过防报错。
   - 光波采样 · 实时测速（默认：开启）：实时记录首字延迟、流式吐字速度与结束原因（finish_reason），同时作为空回/断章自动追击的前置观测器。
   - 波长记忆 · 基线比对（默认：开启）：自动学习当前渠道前 8 轮正常对话的速度特征，后续速度骤变时自动提示疑似偷换底层模型。
   - 信标核验 · 结构指纹（默认：开启）：核验返回 JSON 结构与思考块指纹，揪出“表面回显真模型名、底层偷换廉价模型”的伪装渠道。

4. 精神同调 · 思考强度（默认：跟随预设）
   - 四档可选：跟随预设（完全保留预设原有思考预算，零覆写，最稳妥）/ 低维 / 均衡 / 深度同调。

5. 主动探针与诊断维护
   - 展开圣域诊断报告：逐轮查看模型吻合度、思考预算核验、首字耗时与疑似调包证据。
   - 光波采样悬浮窗：在屏幕上开启实时测速采样小窗。
   - 真伪探针 · 渠道鉴伪 / 频段摸底 · 别名扫描：主动发射极小测试包检验渠道真伪，或扫描当前中转站可用的模型别名。
   - 光波横幅昭示 / 导出圣域卷宗 / 复制排障信标 / 重铸护盾 · 全量自检 / 重置波长记忆 / 焚毁全部卷宗。

⚔️ 二、「形态破甲」页（七档破甲 · 抗截断 · 晚高峰抢跑）
--------------------------------------------------------------------
1. 作战波段 · 话术适配（默认：自动匹配）
   - 七档可选：自动匹配 / 3.8F·极速 / 4A·创作 / 4C·均衡 / 4H·高墙 / 4N·纯净 / 通用·全模型，按模型家族自动匹配最契合的破甲波长；支持点击「保存并锁定方案」永久固定波段（重开酒馆不丢失），更换模型后可点「恢复自动匹配」。

2. 迪迦五形态 + 终极圣域双神（默认：石像待机，按需一键切换）
   * 所有破甲仅作用于当轮发出的请求信号，你聊天框里的历史正文分毫不改！
   - 石像待机：完全关闭正面破甲，原样透传。
   - 空中型（轻装掠行）：仅在请求末尾附上温和虚构创作续写契约，不碰预设正文与参数。
   - 复合型（日常推荐）：挂载「虚构创作许可头」与「保底输出上限」，不改安全阈值、不加文风垫片，100% 保留预设原有文风。
   - 强力型（赤红刚力）：开启完整委托块（权威许可头、任务单、资料标记与正文承载）并放宽安全阈值，正面轰穿常规拒答。
   - 闪耀型（黄金圣辉）：汇聚强力型全集 + 上轮尾句回执 + 续写复用包 + 最底部独立黄金环身圣盾声明。
   - ◤ 诺亚 · 太古圣翼 ◢（宇宙第一道光 · 圣域归位）：在全套破甲之上启动五百条对抗话术中性化清洗，将预设中易触发拦截的敏感元话语温和清洗并归位至「参考资料」区之后，既能过严审又不丢 system 人设与文风。
   - ◤ 凝视深渊 · 终焉暗域 ◢（弃光入暗 · 沉渊接管）：终极黑化档，在诺亚全套能力之上执行彻底降权下沉——将冲突指令段落整段压入 user 参考资料并保留干净角色卡设定，专啃最严苛的上游审查高墙。

3. 能量续航 · 防半截断写（默认：自动接力）
   - 三档总控：关闭 / 续航叮嘱（事前附带完整收尾引导）/ 自动接力（检测到长度截断或半句卡断自动接力补写 1 次）。
   - 收尾封印 · 禁仓促完结（默认：开启）：严禁模型铺垫没写完就匆匆跳过程、强行大结局。
   - 净界律令 · 禁文末自证（默认：开启）：禁止文末附带「字数统计、合规声明、自我点评」等出戏尾注。
   - 追击请示 · 续写前确认（默认：开启）：检测到空回或断章时先弹「光波受阻」确认卡问你要不要补；关掉则全自动静默追击。
   - 记忆凝缩 · 旧轮单节折叠（默认：关闭）：长聊上下文吃紧时可手动开启，自动折叠历史旧轮次中冗余的扩展小节。
   - 武装货舱 · 独立圣柜信道交付（默认：关闭，描述：独立工具通道防截断）：通过 lk_write 函数工具参数把整篇正文一次性打包交回；遇到不支持的酒馆源或末尾含助手预填引子时自动无缝切回常规续航，绝不空回。

4. 飞燕编队 · 高峰并发抢跑 & 时空回溯（PVP）
   - 飞燕编队（默认：编队待命）：可选「飞燕一号·省流」（精简负载压低思考消耗）或「双机齐射·2路 / 胜利合体·3路」（晚高峰同时发多路请求抢跑，采纳最先返回的一路并自动撤回其余请求）。
   - 逆风突围 · 503 自动重连（默认：开启）：遭遇上游 503 拥堵或瞬时故障自动按退避时序重连。
   - 时空回溯 · 异常自动重演（默认：关闭）：遇到 503 / 429 / 超时或无破甲时的空回自动触发重抽（开启后可设 1~3 次单轮上限）。
   - 断流看门狗 · 首字超时重演（默认：关闭）：监测迟迟不吐首字的假死流，超时即刻切断并重发。
   - 回溯时序罗盘：自定义首字看门狗秒数、退避间隔与抖动策略。
   - 底部三枚手动战技键：「破甲追击 / 断章接力 / 原波重演」，单次手动触发，互不抢占自动配额。

🌌 三、「叙事结界」页（防读心 · 去光环 · 反 OOC · 设定打码）
--------------------------------------------------------------------
1. 迷雾结界 · 防角色读心（默认：关闭）
   - 四档可选：关闭 / 仅知在场事 / 禁跨场推理 / 绝对结界。前两档阻止 NPC 隔空读心开天眼并保留正常心理描写；注意最高档「绝对结界」会同步禁止描写任何角色内心独白且禁止代写主角言行。

2. 真实引力 · 去主角光环（默认：关闭）
   - 四档可选：关闭 / 角色独立作息 / 允许干脆拒绝 / 世界自主运转，让配角保持各自日程与脾气，拒绝无脑顺从和主角光环滤镜。

3. 心灵之光 · 角色防跑偏（反 OOC）（默认：关闭）
   - 开启总闸后可按需点亮四项人设护栏：
     * 真名点校 · 核对世界书（出场前核对角色卡与世界书设定）
     * 净除套路 · 禁网文陈词（净除“三分薄凉七分讥诮、瞳孔地震”等油腻套路词）
     * 因果铺垫 · 禁态度突变（好恶与立场转变需有剧情铺垫）
     * 声纹锁定 · 台词口吻一致（锁定角色固有自称、语癖与句式节奏）

4. 设定隐匿 · 圣域折射护航（默认：开启）
   - 设定隐匿 · 敏感词折射（默认：开启）+ 正文显影 · 折射词还原（默认：开启）：仅对发出去的设定段敏感词做无损断词/码点折射骗过网关，流式收到正文时实时无感还原回原词，聊天楼层一字不差。

⚙️ 四、「防卫设置」页（云端更新 · 扫描范围 · 桌宠圆章 · 图鉴）
--------------------------------------------------------------------
1. 光之星轨 · 云端自动更新（默认：开启）
   - 星轨共鸣 · 后台自动更新（默认：开启）：打开酒馆后静默巡检并自动同步新版，个人开关全数保留；关闭后仅在手动点按钮时联网。
   - 星轨巡检 · 手动检查更新：随时手动拉取最新云端清单并一键升级；升级完成且刷新前提供「圣域重载 · 刷新页面生效」与「时空回溯 · 撤回旧版」。

2. 雷达扫描范围与模型过滤
   - 锁定光之国 · 仅巡检 Gemini（默认：开启）：默认聚焦谷歌 Gemini 家族；若使用 Claude / DeepSeek 等非谷歌模型请将其关闭。
   - 纯净记账 · 仅计正文轮次（默认：开启）：仅统计正式剧情对话，自动忽略标题生成或内部摘要请求。

3. 彩色计时器圆章、迪迦桌宠与系统排障
   - 侧边彩色计时器圆章（默认：显示中）/ 异动警报 · 自动展开报告（默认：仅红灯）/ 归位计时器圆章。
   - 闪耀迪迦 · 光之伙伴：控制迪迦桌宠召唤、互动台词气泡与靠边自动合入圆章。
   - 石像休眠 · 暂停全部挂钩（默认：正常）：排查与其它插件冲突时可一键休眠卸载请求钩子。
   - 打开功能图鉴：随时展开内置五页离线《功能图鉴》，支持顶部关键词即时搜索。

🌊 五、实用场景速查（遇到什么情况点哪个键？）
--------------------------------------------------------------------
- 日常跑团 & 保留预设原味：
  导入后直接跑，或去第 2 栏把形态切到「复合型」。
- 普通吃肉 / 轻度被拒：
  去第 2 栏切到「强力型」或「闪耀型」。
- 极高强度题材 / 严苛审查拦截：
  直接开启第 2 栏下方的「◤ 诺亚 · 太古圣翼 ◢」或「◤ 凝视深渊 · 终焉暗域 ◢」，并保持第 3 栏「设定隐匿 · 敏感词折射」开启。
- 遇到写到一半卡断 / 仓促烂尾 / 文末报字数：
  确认第 2 栏「能量续航 → 自动接力」、「收尾封印」、「净界律令」开启；若流式经常半路断掉，可点亮金色的「武装货舱 · 独立圣柜信道交付」，或手动点底部的「断章接力」。
- 遇到晚高峰 503 / 卡死不吐字：
  开启第 2 栏「逆风突围 · 503 自动重连」+「时空回溯 · 异常自动重演」+「断流看门狗」，或把「飞燕编队」切到「双机齐射·2路 / 胜利合体·3路」并发抢跑。

⚠️ 游玩须知与叠甲
--------------------------------------------------------------------
- 关于破限：对于极高强度的题材，请直接采用「诺亚 · 太古圣翼」或「凝视深渊 · 终焉暗域」。如果依然出现道歉或拒答情况，请直接【删除这层楼，重新再发】，千万不要在本楼直接点重试/重Roll！
- 渠道兼容性：本脚本所兼容的渠道为【类脑公益站的各渠道，以及官方的第三方中转】。其他渠道的 Gemini 完全不兼容，可能存在报错和拦截。
- Bug 反馈：代码仍在持续迭代中，遇到问题可在面板第 1 栏点击「复制排障信标」或附上「圣域诊断报告」截图及时反馈！
