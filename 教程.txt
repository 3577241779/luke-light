====================================================================
                  ✨ 卢克之光 V5.7 · 核心功能介绍与使用教程
====================================================================

本插件是一款基于【酒馆助手】的 渠道验伪防调包、星域协同插件放行与预设双态兼容、流式思考/正文精准采样、七档无损破甲、流式抗截断与工具交付、晚高峰并发抢跑（PVP）、重写版防全知与贴脸去媚、3D CG 雕像迪迦桌宠与云端自动更新 一体化脚本。
当前 V5.7 最新版即插即用，默认开关已调优，导入即享满血配置！

--------------------------------------------------------------------
🚀 安装、云端自动更新与三处控制台入口
--------------------------------------------------------------------
1. 首次安装：在【酒馆助手】中导入对应平台（ST酒馆适配 / TT酒馆适配 / 桌面版）的 JSON 脚本并启用，刷新一次页面即可生效。
2. 云端自动更新（光之星轨 · 默认开启）：
   - 打开酒馆后会自动在后台静默检查 GitHub 与多路 CDN 镜像的最新版（单节点旧缓存自动回退下一镜像），拉取对应平台包原地写回酒馆助手，下次刷新即刻升级，全部个人开关、锁定波段与历史卷宗 100% 无损保留。
   - 已装 V5.5 / V5.6 / V5.61 的老用户会自动平滑追新至 V5.7（内部版本 5.70）。
3. 控制台入口（全屏永远最多只留 1 个悬浮物，绝不挡视线）：
   - 魔法棒菜单第一项「光之守护」 / 侧边彩色计时器圆章 / 3D CG 雕像迪迦桌宠（支持点击 3D 神光棒化光变身与全形态联动）。

🛡️ 一、「光之雷达」页（验渠道 · 精准采样 · 防缓存 · 控思考）
--------------------------------------------------------------------
1. 彩色计时器 · 信道守护（默认：开启）与四大防调包护栏（钉参数 / 观察器 / 行为基线 / 结构指纹）。
2. 光波采样悬浮窗（V5.7 重构）：
   - 底层直连流式解析，精准拆分 Gemini 原生 thought:true、reasoning_content / reasoning_details、Anthropic thinking_delta、工具参数正文以及跨分片通用自定义思考/规划标签，根治「思考字数为 0、把思考算成正文」。
   - 顶部实时亮出 [正文]、请求模型 → 实测模型、疑似换芯红警、零思考预警、工具流与放行插件计数。
3. 精神同调 · 思考强度（默认：跟随预设，零覆写预设思考预算）与光波折射 · 防缓存。

3. 能量续航 · 防半截断写（自动接力 / 武装货舱）与飞燕编队 · 503 自动重连 / 时空回溯（PVP）。

🌌 三、「叙事结界」页（V5.7 重写版防全知 & 去媚 + 反 OOC + 脱敏）
--------------------------------------------------------------------
* OpenAI / Claude / Gemini 原生格式全协议生效，只改请求副本，聊天记录零污染！

1. 迷雾结界 · 防角色读心（关闭 / 仅知在场事 / 禁跨场推理 / 绝对结界）：
   - 动笔前先在内部思考锚定 1~2 条本轮不可知盲区；
   - 双向信息隔离（连 <user> 主视角旁白也不能透视未公开设定）；
   - 时间线三点校验 + 反补设定（严禁临时编信、幕外会面或用“你忘了”硬圆前文）；
   - 时代与身份认知天花板（听懂≠全懂）+ 物理遮挡边界 + 同见不同解。

2. 真实引力 · 去主角光环（关闭 / 角色独立作息 / 允许干脆拒绝 / 世界自主运转）：
   - 戏外≠戏内身份解耦 + 意图降格六维过检 + 强制对抗成败结算；
   - 封死 4 类隐蔽暗媚（余光偷瞄 / 莫名心疼吃醋 / 嘴硬背地派人兜底 / 跨级白给）；
   - 双向防双标 + 反神化平衡阀（不硬变全员杠精）+ 结尾去等待化（禁全员停住看 <user>）。
   - 配套 2 个独立子开关：
     * 📦 贴脸包裹（中/高档默认自动联动开）：对最近最多 3 条真实玩家发言（depth 0~2）施加无痕三明治包裹，多行安全，精准跳过塞在 user 里的控制块/思维链。
     * ☠️ 致命后果（默认关闭）：独立硬核求生代价开关，日常/恋爱向保持关闭不误伤，高危求生/跑团向开启后叠加无免死光环与真实生死代价。

3. 心灵之光 · 反 OOC（真名点校 / 净除套路 / 因果铺垫 / 声纹锁定）与 设定隐匿 · 圣域折射护航。

⚠️ 游玩须知与叠甲
--------------------------------------------------------------------
- 关于破限：极高强度题材请直接使用「诺亚 · 太古圣翼」或「凝视深渊 · 终焉暗域」。若仍遇拒答，请【删除这层楼，重新再发】，不要在本楼直接点重试/重Roll。

- Bug 反馈：遇到问题可在第 1 栏点击「复制排障信标」或附上「圣域诊断报告」截图反馈。
