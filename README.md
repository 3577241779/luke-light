## 📦 下载与首次安装（选对对应平台，三选一）

前往本仓库右侧 **[Releases (v5.5)](https://github.com/3577241779/luke-light/releases/latest)** 下载对应平台的导入包：

| 导入包 | 适用平台 | 特性说明 |
|---|---|---|
| `卢克之光 V5.5·ST酒馆适配.json` | 手机 SillyTavern（ST 酒馆） | 移动端触控安全区 / ST 视口打分宿主解析 / 魔法棒 + 圆章双入口 |
| `卢克之光 V5.5·TT酒馆适配.json` | 手机 TT 酒馆 | TT 专属防失联双入口 / 跨层存储同步 / 直连探针鉴权适配 |
| `卢克之光 V5.5·桌面版.json` | 电脑桌面端酒馆 | 桌面宽屏自由拖拽 / 图鉴并排对照 / 完整高帧觉醒光流 |

**安装步骤**：
1. 打开酒馆 → **酒馆助手** → **脚本库** → **导入**，选中对应平台的 `.json` 文件并开启启用开关。
2. 刷新一次页面即可生效（**切勿同时启用两份不同平台的卢克之光**）。

## 🌠 光之星轨 · 云端自动更新（V5.5 新增）

本版已内置云端自动更新，无需每次去群里手动重下：

- **星轨共鸣 · 后台自动更新（默认开启）**：每次打开酒馆后自动在后台静默检查本仓库 `dist/version.json`（自动在 jsDelivr CDN / GitHub Raw / Fastly 三线路间无感切换防超时），发现新版后自动按当前平台拉取对应包原地写回酒馆助手，**下次刷新页面即刻生效**。
- **个人配置 100% 无损保留**：所有形态开关、锁定波段、桌宠与卷宗均独立存储于 `ar6.cfg` / `ar6.log`，更新只替换脚本本体，绝不重置你的配置。
- **极简控制**：打开面板第 4 栏 **「防卫设置」** 顶部即可：
  - 一键开关 **「星轨共鸣 · 后台自动更新」**（关掉则切为仅手动模式，平时零联网）；
  - 随时点击 **「星轨巡检 · 手动检查更新」** 立即查新升级；
  - 升级后刷新前支持 **「圣域重载 · 刷新页面生效」** 或 **「时空回溯 · 撤回旧版」**。

## ⚠️ 游玩须知与叠甲

- **关于破限**：对于极高强度的题材，请直接采用 **「诺亚 · 太古圣翼」** 或 **「凝视深渊 · 终焉暗域」**。如果依然出现道歉或拒答情况，请直接 **【删除这层楼，重新再发】**，千万不要在本楼直接点重试 / 重 Roll！
- **渠道兼容性**：本脚本所兼容的渠道为 **【类脑公益站的各渠道，以及官方的第三方中转】**。其他渠道的 Gemini 完全不兼容，可能存在报错和拦截。
