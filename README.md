## 🌟 V5.7 核心升级亮点

### 1. 星域协同：插件放行 & 预设兼容双独立开关（防卫设置）
- **纯净正轨 · 放行外部插件（默认开启）**：在请求最前门通过 7 层流量特征识别，对生图、检索、数据库填表、结构化 JSON、静默生成等外部插件后台请求执行 0 改写直通放行，不污染光波采样窗与路由账本；同时精准放行正文内的记忆与状态块，不误杀正常对话。
- **多插件 `fetch` 链和平共存**：兼容访问器守卫类插件与外层临时抓包钩子，新增重入锁防死循环；巡检检测到钩子仍在调用链中时不再反复抢链覆盖；静默兼容外部数据库拦截中止信号，杜绝误报错与误重试；修复安全模式休眠下看门狗误补挂的边界问题。
- **预设适配 · 破甲主导权（默认「强权优先」，可切「礼让预设」）**：
  - **强权优先**：以卢克之光破甲为第一优先，保留全上下文码点护甲，并基于工具参数结构自动保护多字段业务引擎工具不被误拆。
  - **礼让预设**：检测到当前上下文已包含同类破甲、工具交付、防全知、去媚或反 OOC 规则时自动温和避重，保留 Token 保底、`BLOCK_NONE`、路由雷达与精准采样。
- **4 项结构安全护栏加固**：文本规整、脱敏与码点护甲全面跳过 XML 闭合标签、Markdown 表格、URL、JSON 键名与 JSONPatch 路径，且不篡改带工具调用与思考签名字段的消息；深渊档原地仅抽离对抗词段落，保留多深度位系统消息；前缀稳定不改坏故事历法日期与数据编号。

### 2. 光波采样悬浮窗 & 流式解析重构
- 从流式解析底层直接输出结构化增量，完整支持 Gemini 原生 `thought: true` 与思考 Token 统计、OpenAI `reasoning_content / reasoning_details`、Anthropic `thinking_delta`、增量工具参数正文提取，以及跨 SSE 分片通用思考/规划标签状态机，彻底修复「思考字数为 0、把思考算成正文」的问题。
- 悬浮窗顶部新增实时星轨路由条：直观展示 `[正文]`、`请求模型 → 实测模型`、`疑似路由/换芯` 红警、`零思考异常` 预警、`工具流` 角标与已放行插件计数。

### 3. 叙述结界重写：迷雾结界（防全知）& 真实引力（去媚）
- **OpenAI / Claude / Gemini 原生格式全协议支持**，仅改当轮请求副本，聊天记录零污染，幂等可逆。
- **迷雾结界 · 防角色读心（低 / 中 / 高）**：升级动笔前内部锚定不可知盲区、双向信息隔离（含主视角旁白不透视未公开设定）、时间线三点校验与反补设定、时代/身份认知上限、物理遮挡边界与同见不同解。
- **真实引力 · 去主角光环（低 / 中 / 高 + 双独立子开关）**：升级戏外/戏内身份解耦、意图降格与六维情境校验、强制对抗成败结算、封死隐蔽暗媚、双向防双标平衡阀与结尾去等待化。
  - **`📦 贴脸包裹`（中/高档默认联动开启）**：对最近 2 轮（最多 3 条）真实玩家发言进行无痕三明治包裹，多行安全，并自动识别跳过系统控制块与工具返回消息，绝不误包指令。
  - **`☠️ 致命后果`（默认关闭）**：独立高危求生代价开关，日常/恋爱向保持关闭不误伤，硬核求生/高危题材按需一键开启。
