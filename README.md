# 卢克之光 · Anti-Route

一个跑在酒馆助手（SillyTavern + JS-Slash-Runner）里的脚本，用来**判断你这轮对话背后的模型有没有被悄悄换掉**，并留下可复查的证据。

- 纯本地，不联网（除你自己填的反代地址）
- 只在 `status >= 400` 时才读错误体，正常的 200 响应体一个字节都不碰
- 只发现、不阻止；判不出来就说判不出来

---

## 装哪个

| 包 | 给谁 |
|---|---|
| `luke-light-desktop.json` | 桌面版酒馆助手 |
| `luke-light-mobile.json` | TT 酒馆（移动端） |

**两个只能装一个**，装两个会出现两套面板抢同一块地方。

---

## 怎么装

1. 打开酒馆助手 → 脚本库 → 导入
2. 选上面那个 `.json`
3. 刷新页面

装完先点一次「验渠道」——这一步决定后面所有结论算不算数。

---

## 一键更新（V0.93 起）

面板 →「体检」那一行：

1. 打开 **⬆ 自动更新**
2. 「版本文件地址」填：

   - 桌面版：`https://github.com/3577241779/luke-light/releases/latest/download/version.json`
   - TT 版：`https://github.com/3577241779/luke-light/releases/latest/download/version-mobile.json`

3. 有新版时，面板上会出现 **⬇ 装新版：0.9x**，点它
4. 提示「已装，刷新一次页面生效」→ 刷新

不放心的话，刷新前可以点 **↩ 撤销更新**。

---

## 它不做什么

- 不阻止请求，也不改响应
- 不上传任何数据
- 不自动下载、不自动替换（一键更新要你点，刷新也要你点）
- 不判断「上游真实身份」——它只比较**你请求的名字**和**对方自称的名字**，以及本地测出来的耗时、速率、返回格式
